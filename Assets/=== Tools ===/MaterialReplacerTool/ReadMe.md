# 材质替换器

这是一个用于批量替换Unity项目中材质的工具。它允许用户选择多个材质并将它们替换为指定的新材质，从而简化了材质管理和更新的过程。

## 零 参考资料
https://docs.unity3d.com/6000.3/Documentation/Manual/UIE-HowTo-CreateEditorWindow.html

## 一 主要功能
1. 查找场景中使用某种 shader 的 material;
2. 将此 material 批量替换为目标 shader;
3. code 修改关键字，或者通过 GUI 修改关键字;
